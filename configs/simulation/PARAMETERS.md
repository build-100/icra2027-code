## Seven-node example

The graph has seven vertices and nine unit edges. Two robots start at [0, 4],
T_max=3, rho_v=rho_g=1, and beta=0.00022829998760764592. This beta is the
fixed historical setting; it was not newly calibrated on the seven-node graph.
Graph files are in `maps/7node`. GEVD uses a 10,000-call training budget;
the QCO/QCF configurations use 20,000 calls. Simulator calls are not episodes.
See [reproducibility notes](../../docs/reproducibility.md) for the manuscript
curve's different horizontal-axis description. The ten saved seeds were
906300, 906301, 906410, 906411, 906412, 906510, 906511, 906512, 906513, 906514.

## Horizon and distance-penalty calibration

1. Enumerate fixed robot priority orders, construct nearest-unvisited-region
   coverage routes, and connect remaining frame components. Choose a feasible
   reference lexicographically by (T, D, routes), without ranking trained returns.
2. Set T_max = T_ref + max(2, ceil(0.15*T_ref)), where T_ref is the reference
   joint-step count. This heuristic is not a theoretical minimum horizon.
3. Insert closed two- or four-edge detours before reference termination while
   other robots execute legal backtracking. Replay actual termination semantics.
   Deduplicate successful candidates with positive deltaS and deltaD.
4. Prefer candidates with deltaD / D_ref <= 0.20; if none exist, use all positive
   feasible candidates and record the fallback.
5. Compute q25 and q75 of deltaS/deltaD and set beta=sqrt(q25*q75).
   With no positive feasible candidate, this calibration rule is undefined.

The nine `calibration/map*_N*.json` files preserve reference paths, candidate
detours, quantiles, fallback flags and final task parameters. The release verifier
checks the stored horizon and beta arithmetic. The seven-node T_max=3 is a preset.

## GEVD and comparison settings

GEVD uses a hidden width of 128, three graph message-passing layers, gamma=1,
batch size 64, a replay capacity of 20,000, Double DQN targets and a 0.1 internal
TD reward scale. The independent retrospective branch is bounded by 0.1|Q|,
with execution multiplier 0.1, Retrace decay 0.9, auxiliary batch size 8,
episode capacity 256 and event sampling fraction 0.5. Its trace covers T_max.

For the nine comparison tasks, the training budget is 25,000 calls; the learning
rate is 5e-5 through C=12,500, then decreases linearly to 5e-6 at C=20,000.
Epsilon decreases to 0.05 at C=15,000. Seven-node GEVD uses 5e-6 initially,
with decay starting at C=10,000 and ending at 5e-7 at C=16,000; epsilon reaches
0.05 at C=12,000. Those schedules are not silently extended by the entry point.

QCO/QCF use an intra-robot weight of 7; QCF adds a 0.5 success reward. QMIX
and COMA retain their own network, optimizer and schedule settings in their YAMLs.
The new GEVD configurations do not establish that every historical table row
was generated by the same GEVD version; see the reproducibility notes.

## Common evaluation

G = (S_T - S_0) + rho_v*(K_T - N) + rho_g*(N - c_T) - beta*D,
with alpha=1/number_of_regions. Selected successful routes and final current
policies are distinct evaluation objects. All runtime paths are project-relative;
CPU is the default and `--device cuda:0` selects an available CUDA device.
